# ==========================================================================
# Scenario 04 - Dynamic events and their effect on later decisions
# --------------------------------------------------------------------------
# PURPOSE
#   Every event type in the format appears here at least once, each placed
#   so it hits a robot or request at a known moment.
#
# LAYOUT
#   A 5 x 4 grid (row-major IDs 1..20) plus three extra connections:
#   32 = 8-7 (cost 8), a PARALLEL road beside connection 6 = 7-8 (cost 5);
#   33 = 13-19 (initially BLOCKED); 34 = 2-8 diagonal. Chargers at 5, 16.
#   speed = 2, so a robot can pass a node and continue in the same step.
#
# WHAT IT TESTS
#   1. EVENTS are deliberately NOT listed in time order. The loader must
#      sort them by time with a STABLE sort, so same-time events keep
#      their file order (required by the specification).
#   2. t=3 BLOCK 29 (13-18): Robot 2 (route 1-6-7-12-13-18-19-20, cost 16)
#      is at node 12 at that moment. The blocked road is in its PLANNED
#      route, not under it, so it must reroute from 12.
#   3. t=4 SET_URGENCY 5 5: Request 5 (urgency 1) jumps ahead of Request 6
#      (urgency 2) while both wait for the only SUPPLY robot (Robot 4).
#      Needs an "update key" operation on the pending-request queue.
#   4. t=5 ROBOT_OFFLINE 1 while Robot 1 is PERFORMING Request 1
#      (zero-length route, duration 10, work started at t=1). Request 1
#      returns to PENDING with its remaining work kept and is reassigned;
#      counted as one reassignment.
#   5. Robot 6 starts with battery 0 at charger 16 and recharges. t=6
#      STATION_DOWN 16 stops it at 24/100 (below 30 %), so it must head to
#      the other charger (5, route cost 18).
#   6. t=8 BLOCK 10 then UNBLOCK 10 (same step): net result OPEN. Robot 6
#      is at node 12 heading over connection 10. Because rerouting is done
#      after ALL events of the step, Robot 6 must NOT reroute.
#   7. t=8 UNBLOCK 33 then BLOCK 33 (same step): net result BLOCKED.
#   8. t=12 BLOCK 6: the cheaper of two parallel roads closes; 7-8 is
#      still reachable through connection 32 (cost 8).
#   9. t=15 UNBLOCK 1 on a road that is already OPEN -> warning, no change.
#  10. t=60 SET_URGENCY 3 1 on an already COMPLETED request -> warning,
#      no change.
#  11. t=30 ROBOT_ONLINE 1 brings the robot back as AVAILABLE.
# ==========================================================================
