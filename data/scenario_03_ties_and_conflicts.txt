# ==========================================================================
# Scenario 03 - Tie-breaking and competition between robots and requests
# --------------------------------------------------------------------------
# PURPOSE
#   Proves the coordinator is deterministic: every tie has exactly one
#   documented winner, so two runs on this file give identical logs.
#
# LAYOUT
#   A hub (1) with four buildings around it (2, 3, 4, 5). Two outer
#   junctions (8 and 9) each sit at EQUAL distance (2) from two buildings,
#   so two robots are always equally close to a request there.
#
# WHAT IT TESTS (request-side ties: which request is served first?)
#   1. Seven requests arrive at t=0. Order must be: higher urgency first,
#      then earlier report time, then smaller request ID.
#   2. Requests 11-15 (all SUPPLY, urgency 3, t=0) are listed OUT of ID
#      order in the file (14, 11, 15, 13, 12). The serving order must be
#      11, 12, 13, 14, 15 (by ID), not file order.
#   3. Request 16 (SUPPLY, urgency 3) arrives at t=1, so it waits behind
#      all of 11-15 even though it has the same urgency.
#
# WHAT IT TESTS (robot-side ties: which robot gets the request?)
#   4. Request 1 at junction 8: Robots 1 and 2 are both at distance 2.
#      Tie broken by HIGHER battery -> Robot 2 (90 vs 80).
#   5. Request 2 at junction 9: Robots 3 and 4 are at distance 2 with equal
#      battery. Tie broken by LOWER robot ID -> Robot 3.
#   6. Request 3 at the hub (SEARCH): Robot 6 (SEARCH) and Robot 5
#      (GENERAL) are both at distance 4. Specialist preferred -> Robot 6,
#      keeping the GENERAL robot free for categories only it can serve.
#   7. Only Robot 5 (GENERAL) can serve SUPPLY, so it serves 11-16 one
#      after another: one robot, many requests.
#
# EXPECTED t=0 ASSIGNMENT ORDER
#   Req 3 (urg 5) -> Robot 6
#   Req 1 (urg 4, ID 1) -> Robot 2
#   Req 2 (urg 4, ID 2) -> Robot 3
#   Req 11 (urg 3) -> Robot 5 ; Req 12..15 wait (no free GENERAL robot)
#   Req 4 (urg 2, MEDICAL at hospital 6) -> Robot 1 (route 2-1-6, cost 7)
#   Conflicts counted at t=0: Req 1, Req 2, Req 3 (more than one candidate).
# ==========================================================================
